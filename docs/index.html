Self-Correcting Discrete Diffusion

Generalized Discrete Diffusion with Self-Correction

A discrete diffusion language model whose sampler can revise incorrect visible tokens without remasking them.

Larry Wang

Code BibTeX

Self-Correction Without Remasking

SCDD keeps the parallel denoising behavior of masked diffusion while allowing visible tokens to transition directly to better visible tokens during sampling.

Method

From masking to self-correction

The forward process mixes absorbing mask corruption with uniform token corruption. The reverse process is trained to recover masked positions and repair visible mistakes, giving the sampler a direct correction path instead of requiring a wrong token to be frozen or remasked.

Experiments

Language modeling and correction

The public code supports training and evaluation on OpenWebText, WikiText-103, and LM1B, along with supplementary correction experiments that probe whether the sampler can recover from visible token errors.
